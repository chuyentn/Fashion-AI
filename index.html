fashionstudio — features
$ AI Banner Creator
Tạo banner quảng cáo thời trang từ ảnh sản phẩm + prompt. Hỗ trợ 5 tỷ lệ khung hình, batch processing.

$ AI Image Extraction
Tách sản phẩm khỏi nền, nhận diện từng món đồ riêng biệt bằng AI. Export PNG trong suốt.

$ Video Lookbook Studio
Tạo video lookbook từ ảnh tĩnh bằng Google Veo 3. Chọn góc quay, chuyển cảnh, hiệu ứng chuyên nghiệp.

$ Smart Prompt Engine
Hệ thống prompt 4 lớp tự động — phân tích sản phẩm, chọn phong cách, tối ưu chi tiết, xuất ảnh chất lượng cao.

$ Multi-Provider API
Tích hợp Gemini 3, GPT Image 2, DALL-E 3. Tự do chọn engine phù hợp với nhu cầu và ngân sách.
